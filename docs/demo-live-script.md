# 영광군의회 「열린소통 ON」 실무 시연 라이브 시나리오 (Live Script)

**문서버전**: DEMO-V1.0  
**최종 UI 기준점**: Commit `4362488` (Apple-inspired UI 전면 리디자인 완료)  
**시연 목표 시간**: 7분 (Short Demo) / 15분 (Full Demo)

---

## 1. 시연 핵심 컨셉 및 3대 메시지

영광군의회 실무진 및 군민 앞에서 선보일 라이브 시연은 다음 3가지 메시지를 명확히 전달하도록 설계되었습니다.

1. **실제 참여가 가능한 디지털 의정 플랫폼**: 단방향 정보 노출이 아닌, 군민이 투표·제안·공감·댓글로 즉시 참여합니다.
2. **실제 DB와 보안 RLS 기반 권한 제어**: 카카오 OAuth 로그인 및 시연용 군민인증을 거쳐 거주 주민만 안전하게 의정에 참여합니다.
3. **제안에서 성과까지 이어지는 4단계 투명 선순환**: `01 시민 제안 ➔ 02 군민 의견수렴 ➔ 03 의회 검토·조치 ➔ 04 성과 확정` 프로세스를 한눈에 보여줍니다.

---

## 2. 시연 대표 Seed Data 선정

시연 중 가장 극적이고 설득력 있는 스토리 전달을 위해 다음 Seed 데이터를 대표 항목으로 지정합니다.

- **대표 Ask (의견수렴)**:
  - **ID**: `10000000-0000-0000-0000-000000000001`
  - **제목**: *영광읍 중앙시장 인근 보행환경 개선을 위한 속도제한 및 안심 펜스 설치에 동의하십니까?*
  - **유형**: yes-no (찬성/반대 직관 투표)
- **대표 Proposal (시민 제안)**:
  - **ID**: `20000000-0000-0000-0000-000000000001`
  - **제목**: *영광읍 중앙시장 야간 보행 안전을 위한 보행자 펜스 및 LED 가로등 설치 요청*
  - **상태**: review (검토중, 타임라인 및 의회 답변 보유)
- **대표 Outcome (함께 바꿨습니다 성과)**:
  - **ID**: `30000000-0000-0000-0000-000000000001`
  - **제목**: *영광읍 중앙시장 보행자 안심 펜스 설치 및 속도제한 완료*
  - **상태**: published (Result Surface & 4단계 Journey 시각화)

---

## 3. 브라우저 세션 구성 (Session Window Setup)

시연 안정성을 극대화하기 위해 2개의 브라우저 프로필을 미리 준비합니다.

- **Window A (Chrome Profile A — 시민 세션)**:
  - 카카오 로그인 미완료 또는 일반 member 계정 준비
  - URL: `http://localhost:3000` (또는 HTTPS Demo URL)
- **Window B (Chrome Profile B — 관리자 세션)**:
  - `council_staff` 또는 `admin` 로그인 세션 상시 유지
  - URL: `http://localhost:3000/admin`

## 5. 15분 Full 시연 스크립트 (Full Demo)

1. **Part 1. 서비스 소개 및 비로그인 화면 (2분)**:
   - 메인 랜딩 (`/`), Hero 배너, `듣습니다`, `묻습니다`, `함께 바꿨습니다` 3축 구조 및 서비스 목적 소개.
2. **Part 2. 시민 제안 탐색 및 공감 (2분)**:
   - `/listens` 제안 목록 ➔ 대표 Proposal 상세 (`/listens/20000000...`) 스토리 탐색, 공감 횟수 및 댓글 토론 확인.
3. **Part 3. 군민인증 워크플로우 (3분)**:
   - `/verification` 진입 ➔ 4-Step Indicator ➔ 시연용 본인확인 ➔ 11개 읍면 중 '영광읍' 선택 ➔ 거주확인 신청 제출.
4. **Part 4. 관리자 컨트롤 타워 및 인증 승인 (3분)**:
   - Window B `/admin` 대시보드 진입 ➔ Pending Work 알림 ➔ `/admin/verifications` 신청 내역 확인 ➔ `승인` 버튼 클릭.
5. **Part 5. 묻습니다 안건 투표 및 댓글 참여 (2분)**:
   - Window A로 복귀 후 `/asks/10000000...` 안건 진입 ➔ `찬성` 투표 실행 ➔ 실시간 Progress 바 확인 ➔ 의견 댓글 작성.
6. **Part 6. 성과 Showcase 및 관리자 대시보드 요약 (3분)**:
   - `/outcomes/30000000...` Result Surface Box 및 출발점 연결 확인 ➔ `/admin` 통합 대시보드의 서비스 Health 및 Audit Log 감사 내역 시연 마무리.
